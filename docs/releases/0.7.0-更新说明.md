# Kurisu 0.7.0

- 接入用户确认的最终 A6 脸型，保留柔和左侧，右侧稍恢复外扩。
- 直接缩放到最终显示像素，保留已确认的下巴轮廓。
- 打字细化为 16 个节奏帧：预备、按下、回弹及不等长的小停顿。
- 手腕与袖口有轻微错开的动作，幅度为一至二输出像素。
- 进入、等待、退出分别使用 12 帧；等待呼吸循环为 3.6 秒。
- 进入/退出对齐头顶位置，采用缓入缓出，减少重影。
- 动画更新时钟为 24 Hz，既有原动作仍使用各自的时间参数。
- 保留普通、长待机和打字状态之间的头部比例。
