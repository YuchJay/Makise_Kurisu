# Kurisu 0.8.4 · 点击动作与尺寸调整

## 点击小人

- 恢复原有“开心”动作，同时切换随手工具面板。
- 五帧分别按普通待机的头顶、额头宽度缩放，保持清晰像素。
- 渲染和透明点击区域使用同一套调整后的素材。
- 点击可接管上一轮打字状态；新的键盘活动仍可立即触发打字。

## 坐下打字

- 整体放大约 5%，内容从 155 × 168 改为 163 × 176 像素。
- 使用已确认的 A6 原素材直接缩放，保留脸型、眼神和服装。
- 同步更新进入、打字、等待和退出动画，重新映射手腕与呼吸区域。
- 之前的测量包含较低处的长发外缘，低估了视觉差异；
  调整后更接近待机头部大小，低头角度和头型仍会影响轮廓。
