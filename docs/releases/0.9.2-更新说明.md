# Kurisu 0.9.2 · DeepSeek 网页入口

## 在哪里打开

- 小人右键菜单和菜单栏：**打开 DeepSeek**。
- 随手工具面板右上角：**DeepSeek**。

## 打开规则

1. 使用系统默认浏览器，入口为 `https://chat.deepseek.com/`。
2. 浏览器未运行：直接启动并打开网页。
3. 浏览器已运行：Safari、Chrome、Edge、Brave 查找已有 DeepSeek 标签页并切换；
   不刷新页面、不清空现有会话。没有时再打开新页面。
4. 不跨浏览器搜索。多个 DeepSeek 标签页存在时选中遇到的第一个。
5. 无法查找时，弹窗说明原因，由用户选择普通链接打开或取消；
   普通打开可能新建标签页，不宣称一定复用。

## 权限与数据

首次查找现有标签页，macOS 可能提示允许 Kurisu 控制默认浏览器。
需要用户确认“自动化”权限，与输入监控权限无关。
仅检查标签页地址，不读取正文、登录信息或聊天内容，不自动登录、不提交问题。
无需 DeepSeek API 或密钥。入口只在用户点击时执行，不在应用启动时查找浏览器。

浏览器脚本在后台执行，按钮在处理期间禁用，避免同时触发多次打开。
网页打开/切换后显示情境气泡，遵守原有气泡开关。
浏览器不支持或未授权时不默默重复新建页面。

## 交付范围

本机编译通过，固定输入监听组件继续复用。
没有执行浏览器自动化授权或实际标签页切换验收，未运行自动化测试。
默认浏览器登录、网络与系统授权仍以实际使用结果为准。
