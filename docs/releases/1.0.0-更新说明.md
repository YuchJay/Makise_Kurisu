# Kurisu 1.0.0 · 悬浮卡 DeepSeek 入口

- 按用户要求将主应用版本直接更新为 **1.0.0**，build **20**。
- 鼠标悬浮小人后，信息卡右上角新增 **DeepSeek** 按钮。
- 点击收起卡片并打开网页；仅悬浮不启动浏览器、不申请自动化权限。
- 与工具面板、右键/菜单栏入口共用同一打开逻辑和处理中状态。
- 保持悬浮卡 304 × 270 尺寸及原有便签、暂存、剪贴板和专注摘要。

浏览器未运行时拉起；默认 Safari、Chrome、Edge、Brave 已有标签时优先切入。
首次查找标签可能需要浏览器自动化授权；失败或不支持时明确提供普通打开/取消。
详见 0.9.2 更新说明。输入监听组件版本与二进制不因主应用版本号变更而更新。

版本号按用户要求调整，不表示原有待验收事项已通过；
