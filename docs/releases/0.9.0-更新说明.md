# Kurisu 0.9.0 · 固定监听组件与授权引导

## 使用方式

1. 打开桌宠设置，点 **“我授权，开启打字响应”**。
2. 在 macOS 输入监控中允许 **“Kurisu 输入监听”**。
3. 返回桌宠，等待状态变为 **“监听已开启”**；连接由应用自动处理。

这次首次需要给新监听组件确认一次。原来授权的 `Kurisu.app` 不再负责监听。
普通桌宠更新会复用固定组件，减少更新后反复移除、添加的操作。

## 改动

- 监听拆为独立小应用，放在固定的 Application Support 目录。
- 监听源码不变时复用已有组件，不重新编译、覆盖或签名。
- 授权状态与连接分别显示；系统确认后自动连接，必要时只重启组件。
- 保留 0.8.6 的快捷键排除、连续文字键确认、安全输入暂停等规则。
- 后台通信只传活动结果，不传文字；桌宠退出后组件随之退出。

## 必须保留的系统步骤

系统开关仍由你确认。如果列表没有自动出现，在设置页展开
**“系统列表里没有出现？”**，定位并添加 `KurisuInputAgent.app` 一次。
监听组件自身更新、重装或系统权限重置仍可能要求再次授权。
