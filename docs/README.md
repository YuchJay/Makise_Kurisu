## 阅读与维护约定

- 当前状态以 `STATUS.md` 为入口，未完成事项以 `TRACKER.md` 为准。
- 功能“已实现”、构建“通过”、用户“确认”和版本“已推送”分别记录，不互相替代。
- `PROGRESS.md` 和旧版本说明是历史事实；旧参数被替代时保留历史，在当前规范中写新值。
- 本套文档中的“待验收”表示缺少当前版本的实际验证记录，不自动等同于存在缺陷。
- 责任分工：开发执行者维护代码和记录，用户确认体验及系统权限；当前没有分派给其他成员。
- 仓库内 `docs/` 是维护源；`outputs/project-documentation/` 和压缩包是可分享快照，
  后续更新应重新导出，不能只改快照。

本次仅整理文档、读取版本和 Git 信息，没有构建、运行应用或执行功能测试。
