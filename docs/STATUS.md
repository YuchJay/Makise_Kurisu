## 已知边界

| 边界 | 对体验的影响 | 跟踪 |
|---|---|---|
| 输入监控仍需系统确认 | “我授权”只能发起流程，不能代替 macOS 开关 | T-001 |
| 组件自身更新仍使用临时签名 | 换组件、清空导出包后重建或权限重置，仍可能重新授权 | T-002、D-005 |
| 按键行为不能证明输入框插入文字 | 游戏字母连按可能误判，慢速单字可能不启动 | T-003 |
| 使用时长为交互估算 | 长时间静态阅读/播放可能低估，不等于系统屏幕使用时间 | T-007 |
| 剪贴板历史只在内存 | 退出后不保留；机密标记以外不自动判断敏感内容 | T-007 |
| 当前目标为 arm64、本机临时签名 | 未覆盖 Intel、正式签名、公证和广泛分发 | 非本轮承诺 |
| 角色与素材为个人同人用途来源 | 记录来源不代表取得公开再分发授权 | ASSETS |
