# Kurisu 0.5.0

已将用户确认的 C 高光版本接入打字动画。

- 棕红头发、蓝青瞳孔、小高光、微微低头看屏幕。
- 坐在木桌后使用红色电脑。
- 八帧打字：前臂轻微敲键、头部轻微起伏。
- 暂停输入时保留电脑、缓慢呼吸，随后回到待机。
- 进入/退出使用短暂淡入淡出与轻微下沉；再次打字可反转退出。
- 保持 96 × 104 逻辑像素和 192 × 208 动画帧。

素材动画由已批准图片进行局部像素位移生成，没有再次重画眼睛。
原始跑动、待机和输入监测逻辑沿用。
