# Kurisu 0.8.5 · 情境气泡

替换已确认的 22 类功能气泡文案，覆盖便签、暂存、复制和剪贴板历史、
保持唤醒、休息提醒及通用操作反馈。

## 口吻

- 事情先办妥，再顺口吐槽；关心放在提醒和补充里。
- 日常有一点好胜和小得意，休息提醒更强硬。
- 偶尔使用作品梗，减少反复否认、结巴和泛用客服表达。
- 失败时认真说明下一步，不归咎用户。

## 示例

- 便签：「记好了。脑子留着思考，别拿来当便签纸。」
- 暂存：「暂时替你保管。……谢一次就够了。」
- 唤醒：「电脑可以保持唤醒，人可没有这个开关。明白？」
- 休息：「休息时间到了。别拿“马上就好”当论据。」
- 延后：「五分钟。是五分钟，不是你口中的“再一下”。」

台词为桌宠原创文案，不是原作台词摘录。不加入应用无法感知的视觉观察。
随机选择、同事件避免连续重复、自动剪贴板反馈限流、气泡开关和提醒按钮
沿用原有机制。
