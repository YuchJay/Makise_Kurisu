## 当前验收清单

下列各项当前结果均为 **未执行（0.9.0）**。

### A-001 · 首次权限和自动连接（R-015 / T-001、T-005）

前置：用户已解锁，本地 0.9.0 打开；新组件尚未取得授权。
若机器已授权，不清空权限以制造首次场景，应另记“已授权重连”，首次场景留待合适环境。

1. 在设置点“我授权，开启打字响应”。
2. 观察系统授权对象是否为“Kurisu 输入监听”。
3. 用户完成系统确认；记录是否自动出现在列表，还是需要使用折叠帮助手动加入。
4. 返回桌宠，观察是否自动变成“监听已开启”，再输入一小段示例文字。

预期：不要求重新移除添加桌宠主应用；授权后组件连接、打字形态触发；
拒绝时明确显示未授权，工具功能仍可用。系统没有自动加入列表时，
允许记录一次性手动添加，但不能将该结果写成“全程仅点一次”。

### A-002 · 普通更新保留授权（R-015 / T-002）

前置：A-001 通过；用户允许本次构建与重启应用。

1. 记录已授权组件的 BuildID、可执行文件哈希和权限状态。
2. 仅变更主应用（或重建主应用），不更改 InputAgent、Shared 或组件构建脚本。

4. 再打开应用，观察组件哈希、系统授权和真实打字响应。

预期：组件保持不变，已有授权可继续使用，不再移除、添加或重启整个系统。
仅哈希一致但尚未实际授权的结果，只能登记为 E-005，不能关闭 T-002。

### A-003 · 普通文字与输入法（R-014 / T-003）

1. 在文本编辑器连续输入字母、数字和标点，相邻两次按下间隔小于 0.8 秒。
2. 输入 Shift 大写/符号、Caps Lock 大写；使用中文输入法输入拼音并选词。
3. 输入后停顿、继续，观察坐下、打字、等待、起身及关闭中反转。

预期：连续文字键确认后进入；空格选词可延续近期打字；
单独切换输入法或只按 Shift 不进入。低于阈值的孤立按键不保证触发。

### A-004 · 快捷键与释放顺序（R-014 / T-003）

1. 分别执行 Cmd+C/V/A、Ctrl 组合、Option 组合、Fn 组合。
2. 按住 Cmd，再按住一个字母；先松 Cmd，字母仍按着；最后松字母。
3. 松开后重新连续输入两个文字键。
4. 在已打字时按下上述修饰键，观察原节奏是否被打断。

预期：组合键不启动或续接打字；先松修饰键不使剩余键的连发重新触发；
完整释放后能重新确认。Option+文字即使能生成符号也按当前保守规则排除。

### A-005 · 导航、功能键与长按（R-014 / T-003）

1. 从待机分别按方向、Esc、Tab、Home/End、Page Up/Down 和功能键。
2. 从待机单独长按一个字母。
3. 已确认打字后使用退格、空格或回车。

预期：导航、功能键和单键连发不独立启动；删除/空格/回车仅延续近期确认的打字。
Fn/功能键具体事件受键盘和系统设置影响，记录测试键盘类型。

### A-006 · 鼠标打断与慢速输入（R-014 / T-003）

1. 文字输入后点击、滚动，再只输入一个孤立文字键。
2. 以超过 0.8 秒间隔输入孤立文字，观察是否保持待机。
3. 再恢复正常连续输入。

预期：点击和滚动清除确认；慢速孤立文字可能不启动；连续输入恢复。
电脑收起应经过既有退出动画，不要求一个渲染帧内消失。

### A-007 · 安全输入与监听不可用（R-014 / T-003）

在用户允许的安全输入场景（如终端的安全键盘输入选项）检查状态，然后退出该场景。
不记录或显示真实密码。另观察未授权或组件未连接时输入是否误触。

预期：安全输入期间不响应打字，状态可解释；结束后可恢复；
不能仅凭聚合按键计数误触打字。

### A-008 · 点击、拖动与打字优先级（R-004 / T-007）

打字时点击小人、打开工具；反向拖动再放下；之后重新打字。

预期：点击开心动作仍存在；左右拖动方向正确；不出现“看起来点击但执行拖动”；
新的文字输入可恢复打字，不被旧鼠标动作长期遮挡。

### A-009 · 暂停、隐藏、锁屏和睡眠（R-018 / T-004）

1. 暂停后输入，继续后重新输入。
2. 隐藏后查看菜单，再恢复显示。
3. 用户安排锁屏、熄屏或睡眠，再返回桌面。

预期：暂停/会话失活/熄屏停止监听，恢复后重新连接；不累计旧打字节奏。
隐藏只隐藏桌宠，不等价暂停监听。休息计时与悬浮卡不在锁屏时继续触发。

### A-010 · 组件退出与心跳恢复（T-004）

在用户授权故障演练后，分别观察组件意外退出、主应用正常退出及主应用意外终止。

预期：组件退出后主应用尝试恢复并清空旧节奏；主应用退出后不残留持续监听；
心跳丢失超过 3 秒停止监听、超过 30 秒退出，主应用进程消失可提前退出。
实际测量记录延迟和误差，不把代码常量当测量值。

### A-011 · 登录启动（R-018 / T-006）

用户开启登录启动并完成系统允许后，自行登出/重启；记录桌宠、组件及原有授权状态。

预期：能启动主应用，组件按既有授权连接，没有重复实例或额外独立登录项。
用户未安排重启时保留未执行。

预期：主要按钮可找到，中文不截断；授权对象明确；
约 0.45 秒显示、约 0.32 秒离开宽限；悬浮不抢输入焦点、不暴露剪贴板正文；

### A-013 · 像素与动作一致性（R-001～R-005 / T-007）

在小/标准/大尺寸比较待机、点击、坐下打字和长待机坐姿，检查红色电脑、
向下视线、高光、服装、脸型和方向；闲置超过 90 秒后继续观察一轮坐姿活动。

预期：最近邻清晰像素；打字使用 163 × 176 内容的当前素材，
头部视觉协调；休息入场一次后保持呼吸/偶尔点头，不反复起坐。
此项以用户视觉确认作为结论，不能只凭额头宽度数字判“完全一致”。
